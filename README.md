## 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/my-portfolio.git
```

Go to project folder

```bash
cd my-portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```
